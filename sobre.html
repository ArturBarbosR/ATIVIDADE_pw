Sobre o projeto

Uma experiência esportiva digital

O LittleLion foi criado como um projeto acadêmico utilizando HTML, CSS e JavaScript.

A proposta é apresentar uma interface inspirada em plataformas modernas de entretenimento esportivo, trabalhando conceitos de navegação, responsividade, organização visual e interação.

⚠️ Projeto exclusivamente demonstrativo

Os créditos, eventos e jogos apresentados não possuem valor financeiro real.
